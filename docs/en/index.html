Texas Hold'em Points Lobby Source Code

A focused C++/Tars match server reference for poker points lobbies, coin lobbies, clubs, room messaging, and multiplayer tournament workflows.

View Source on GitHubView Product Screens

Scope and Positioning

This project focuses on Texas Hold'em points lobby source code, coin lobby services, and tournament infrastructure. Public code covers match services, game lifecycle handlers, protocols, timers, rewards, orders, and configuration.

A complete Unity Assets directory is not public. The repository alone is therefore not a buildable full client.

Core Areas

Matches and Rooms

MatchServer, MatchServant, and Tars interfaces for matchmaking, game start, and room communication.

Poker Games

Classic Hold'em, 6+ Short Deck, blinds, insurance, timers, dealing, leaving, and settlement.

Tournaments

SNG and MTT workflows, tournament reward configuration, and order service interfaces.
