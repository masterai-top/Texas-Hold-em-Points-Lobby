聚焦積分大廳、金幣大廳、德州比賽及多人賽事，公開 C++/Tars 配對服務、牌局流程、房間訊息、訂單介面與獎勵設定。

專案定位與公開範圍

本專案主攻德州撲克積分大廳原始碼、金幣大廳原始碼與賽事伺服器，可作為多人房間、比賽配對、短牌、保險、獎勵及訂單流程的技術參考。

公開倉庫未包含完整 Unity Assets 目錄，因此無法只憑目前檔案建置完整客戶端。

主要功能

比賽與配對

MatchServer、MatchServant 與 Tars 介面涵蓋配對、開局及房間通訊。

玩法與牌局

經典德州、6+ 短牌、盲注、保險、計時、發牌、離桌及結算。

賽事與營運

SNG/MTT 流程、比賽獎勵設定與訂單服務介面。
